# QuanRobotics Repository Documentation Standard

## 1. Purpose

This standard defines the minimum documentation requirements for
QuanRobotics technical repositories.

Repository documentation must allow another contributor to understand,
configure, execute, test, reproduce, review, and safely communicate the
repository without depending on undocumented verbal knowledge.

---

## 2. Documentation Principles

QuanRobotics documentation must be:

- Technically accurate
- Reproducible
- Current
- Security-aware
- Clear about maturity
- Explicit about known limitations
- Traceable to technical evidence
- Understandable by a new contributor

Documentation must not overstate implementation maturity, benchmark
performance, security status, or release readiness.

---

## 3. Canonical Documentation Location

Technical repository documentation should be stored under:

`docs/`

The following location is considered canonical:

```text
repository/
├── README.md
└── docs/
